🛠 Ход выполнения работы
1. Открытие терминала GNU/Linux
Для выполнения лабораторной работы был открыт терминал операционной системы Ubuntu, запущенной в среде WSL на Windows 11.

В терминале выполнялись основные команды оболочки GNU/Linux для работы с файлами и каталогами.

2. Определение текущего каталога
Для определения текущего рабочего каталога использовалась команда:

pwd

Команда pwd выводит полный путь к текущему рабочему каталогу.

В результате был отображён путь:

/home/home

3. Просмотр содержимого текущего каталога
Для просмотра списка файлов и каталогов использовалась команда:

ls

Команда выводит содержимое текущего каталога.

Для просмотра всех объектов, включая скрытые файлы, использовалась команда:

ls -a

Параметр -a позволяет отображать скрытые файлы и каталоги, имена которых начинаются с точки.

Для получения подробной информации об объектах можно использовать:

ls -l

4. Смена текущего каталога
Для перехода между каталогами используется команда:

cd имя_каталога

Например:

cd /etc

Для перехода в домашний каталог пользователя:

cd ~

Для перехода на уровень выше:

cd ..

Таким образом, с помощью команды cd можно перемещаться между каталогами файловой системы.

5. Создание нового каталога
Для создания каталога используется команда:

mkdir имя_каталога

Например:

mkdir new_dir

В результате был создан новый каталог:

new_dir

Проверить его наличие можно командой:

ls -l

6. Удаление пустого каталога
Для удаления пустого каталога используется команда:

rmdir имя_каталога

Например:

rmdir new_dir

Команда rmdir удаляет только пустые каталоги.

Если каталог содержит файлы или другие каталоги, для его удаления вместе с содержимым используется команда:

rm -r имя_каталога

7. Создание пустого файла
Для создания пустого файла используется команда:

touch имя_файла

Например:

touch newfile.txt

После выполнения команды был создан пустой файл newfile.txt.

Также файл можно создать с помощью перенаправления вывода:

> newfile.txt

Оператор > создаёт файл, если он отсутствует, либо очищает существующий файл.

8. Копирование файлов
Для копирования файлов используется команда:

cp источник назначение

Например:

cp file.txt copy.txt

В результате создаётся копия файла file.txt с именем copy.txt.

Для копирования каталога вместе с его содержимым используется параметр -r:

cp -r каталог1 каталог2

Параметр -r означает рекурсивное копирование.

9. Перемещение и переименование файлов
Для перемещения файлов используется команда:

mv источник назначение

Например:

mv file.txt /tmp/

Эта команда перемещает файл file.txt в каталог /tmp.

Команда mv также используется для переименования файлов:

mv oldname.txt newname.txt

В результате файл oldname.txt получает новое имя newname.txt.

10. Удаление файлов
Для удаления файла используется команда:

rm имя_файла

Например:

rm newfile.txt

Для удаления каталога вместе со всем его содержимым используется:

rm -r имя_каталога

Следует учитывать, что удалённые с помощью rm файлы обычно не помещаются в корзину.

11. Поиск файлов
Для поиска файлов и каталогов используется команда:

find

Например, для поиска файлов с расширением .txt в текущем каталоге и его подкаталогах:

find . -name "*.txt"

Для поиска файла с определённым именем можно использовать:

find . -name "file.txt"

Команда find позволяет выполнять поиск объектов по имени, типу, размеру и другим параметрам.

12. Использование шаблонов
Для работы с группами файлов можно использовать специальные символы-шаблоны.

Например:

ls *.txt

Команда выводит все файлы с расширением .txt.

Символ * обозначает любое количество произвольных символов.

Также можно использовать знак ?, который соответствует одному произвольному символу.

Например:

ls file?.txt

Команда найдёт файлы вида file1.txt, file2.txt и т. п.

13. Создание символической ссылки
Для создания символической ссылки используется команда:

ln -s источник ссылка

Например:

ln -s file.txt link.txt

В результате создаётся символическая ссылка link.txt, указывающая на файл file.txt.

Проверить ссылку можно командой:

ls -l link.txt

В выводе будет отображаться направление ссылки на исходный файл.

14. Оценка свободного дискового пространства
Для просмотра информации о занятом и свободном дисковом пространстве используется команда:

df -h

Команда отображает:

общий размер файловой системы;
использованное пространство;
доступное пространство;
процент использования;
точки монтирования.
Параметр -h отображает информацию в удобном для человека формате, например в гигабайтах и мегабайтах.

💻 15. Работа в Midnight Commander
В ходе лабораторной работы также была изучена программа Midnight Commander — файловый менеджер для операционных систем GNU/Linux, работающий в терминале.

Для запуска программы используется команда:

mc

После запуска открывается двухпанельный интерфейс Midnight Commander.

С помощью Midnight Commander были выполнены следующие действия:

просмотр файловой системы;
отображение содержимого каталогов;
отображение каталога в виде дерева;
получение информации о файлах;
быстрый просмотр содержимого файлов;
сортировка файлов по размеру;
сортировка файлов по дате изменения;
сортировка файлов по имени;
просмотр файла /etc/fstab;
создание файла newfile;
редактирование созданного файла;
создание каталога new_dir.
15.1. Создание файла в Midnight Commander
Для создания нового файла используется сочетание клавиш:

Shift + F4

После нажатия комбинации открывается редактор Midnight Commander.

Был создан файл:

newfile

После ввода текста файл был сохранён.

15.2. Создание каталога в Midnight Commander
Для создания нового каталога используется клавиша:

F7

С помощью данной команды был создан каталог:

new_dir

15.3. Просмотр файла /etc/fstab
В Midnight Commander был открыт файл:

/etc/fstab

С помощью встроенного средства просмотра можно ознакомиться с содержимым файла без его изменения.

15.4. Сортировка файлов
В Midnight Commander можно изменять порядок отображения файлов.

Была изучена сортировка:

по имени;
по размеру;
по времени изменения.
Это позволяет быстро находить необходимые файлы и анализировать содержимое каталогов.

❓ Ответы на контрольные вопросы
1. Какую команду необходимо использовать для вывода текущего каталога?
Используется команда:

pwd

Она выводит полный путь к текущему рабочему каталогу.

2. Какую команду необходимо использовать для вывода содержимого каталога?
Используется команда:

ls

Для просмотра скрытых файлов применяется:

ls -a

3. Какую команду необходимо использовать для смены текущего каталога?
Используется команда:

cd

Например:

cd /tmp

4. Какую команду необходимо использовать для создания нового каталога?
Используется команда:

mkdir

Например:

mkdir new_dir

5. Какую команду необходимо использовать для удаления каталога?
Для удаления пустого каталога используется:

rmdir

Для удаления каталога вместе с его содержимым:

rm -r

6. Какие команды необходимо использовать для создания пустого файла?
Можно использовать:

touch имя_файла

или перенаправление вывода:

> имя_файла

7. Как обозначается оператор перенаправления вывода?
Оператор перенаправления вывода обозначается символом:

>

Например:

> newfile.txt

8. Какую команду необходимо использовать для копирования объектов?
Используется команда:

cp

Для копирования каталогов вместе с содержимым:

cp -r

9. Какую команду необходимо использовать для перемещения объектов?
Используется команда:

mv

Эта же команда применяется для переименования файлов и каталогов.

10. Какую команду необходимо использовать для удаления файлов?
Используется команда:

rm

11. Как выполнить поиск файлов и каталогов?
Используется команда:

find

Например:

find . -name "*.txt"

12. Как создать символическую ссылку?
Используется команда:

ln -s

Например:

ln -s file.txt link.txt

13. Как определить количество свободного места на диске?
Используется команда:

df -h

Она отображает информацию об общем, занятом и доступном дисковом пространстве.

14. Для чего используется Midnight Commander?
Midnight Commander — это файловый менеджер, работающий в терминале GNU/Linux. Он позволяет просматривать, создавать, удалять, копировать, перемещать и переименовывать файлы и каталоги с помощью удобного двухпанельного интерфейса.

15. Как запустить Midnight Commander?
Для запуска программы используется команда:

mc

16. Какая клавиша используется для создания каталога в Midnight Commander?
Для создания каталога используется:

F7

17. Какая комбинация клавиш используется для создания и редактирования файла в Midnight Commander?

Shift + F4
