12. Изучение прав доступа
Права доступа к файлу можно посмотреть командой:

ls -l file_12

Права имеют три группы:

u (user) — владелец;
g (group) — группа;
o (others) — остальные пользователи.
Также используются обозначения:

r — чтение;
w — запись;
x — выполнение;
- — право отсутствует.
12.1. Права 600
chmod 600 file_12
ls -l file_12

Права 600 означают:

владелец: чтение и запись;
группа: нет прав;
остальные: нет прав.
12.2. Права 644
chmod 644 file_12
ls -l file_12

Права 644 означают:

владелец: чтение и запись;
группа: чтение;
остальные: чтение.
12.3. Права 755
chmod 755 file_12
ls -l file_12

Права 755 означают:

владелец: чтение, запись и выполнение;
группа: чтение и выполнение;
остальные: чтение и выполнение.
12.4. Символьное изменение прав
Также можно изменять права с помощью символьной записи:

chmod g+rw file_12
ls -l file_12

Команда добавляет группе права чтения и записи.

Для удаления права записи у остальных:

chmod o-w file_12
ls -l file_12

После выполнения эксперимента права были возвращены:

chmod 644 file_12
ls -l file_12

15. Изучение файловой структуры Linux
Корневой каталог Linux обозначается:

/

Некоторые основные каталоги:

/bin — исполняемые команды и программы;
/tmp — временные файлы;
/usr — программы, библиотеки и другие пользовательские компоненты системы;
/etc — конфигурационные файлы системы;
/dev — специальные файлы устройств;
/home — домашние каталоги пользователей;
/root — домашний каталог суперпользователя;
/var — изменяемые данные, например журналы;
/proc — виртуальная файловая система с информацией о процессах и ядре;
/sys — информация об устройствах и подсистемах ядра.
Для просмотра корневого каталога:

ls -l /

Контрольные вопросы
1. Что представляет собой файловая система Linux?
Файловая система Linux представляет собой иерархическую структуру каталогов и файлов, начинающуюся с корневого каталога /. В Linux файлами считаются обычные файлы, каталоги и специальные файлы устройств.

2. Что обозначают . и ..?
. обозначает текущий каталог, а .. — родительский каталог, то есть каталог, расположенный на один уровень выше.

3. Для чего используется команда pwd?
Команда pwd показывает полный путь к текущему рабочему каталогу.

4. Для чего используется команда ls?
ls используется для просмотра содержимого каталога. Ключ -l показывает подробную информацию о файлах, а -a включает скрытые файлы.

5. Для чего нужна команда cd?
cd используется для перехода из одного каталога в другой.

6. Как создать каталог?
Для создания каталога используется команда:

mkdir имя_каталога

7. Как удалить файл?
Для удаления файла используется:

rm имя_файла

8. Чем отличаются cp и mv?
cp копирует файл или каталог, сохраняя исходный объект. mv перемещает объект или используется для его переименования.

9. Для чего используется cat?
cat позволяет вывести содержимое файла на экран, а также объединять содержимое нескольких файлов.

10. Что делает команда grep?
grep выполняет поиск строк, соответствующих указанному шаблону.

11. Что означают права r, w, x?
r — чтение, w — запись, x — выполнение.

12. Для каких пользователей задаются права доступа?
Права задаются для трёх категорий:

владельца файла (u);
группы (g);
остальных пользователей (o).
13. Для чего используется chmod?
chmod изменяет права доступа к файлам и каталогам.

14. Что означают права 644?
644 означает:

владелец — чтение и запись;
группа — только чтение;
остальные — только чтение.
15. Что означают права 755?
755 означает:

владелец — чтение, запись и выполнение;
группа — чтение и выполнение;
остальные — чтение и выполнение.
16. Чем отличается символическая ссылка от жёсткой?
Символическая ссылка является отдельным объектом, содержащим путь к другому файлу. Жёсткая ссылка указывает на тот же inode, что и исходный файл, поэтому обе записи обращаются к одним и тем же данным.

17. Для чего используется команда whoami?
whoami выводит имя текущего пользователя.

18. Для чего используется команда id?
id показывает идентификатор пользователя, идентификатор основной группы и список групп, в которые входит пользователь.

19. Для чего используется команда groups?
groups показывает группы текущего пользователя.

20. Для чего используется ps?
ps показывает информацию о запущенных процессах.

21. Для чего используется find?
find используется для поиска файлов и каталогов по заданным условиям.

22. Что такое inode?
Inode — структура файловой системы, содержащая служебную информацию о файле, включая права доступа, владельца, размер и другие атрибуты. Жёсткие ссылки на один файл имеют один и тот же inode.
